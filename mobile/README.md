# Family Budget: мобильное приложение (Flutter)

Мобильная версия сайта https://bis-kbtu.vercel.app. Работает с тем же backend и теми же аккаунтами.
Ответственный: 24B031914 (bekzhanym).

## Часть 1 (MVP, неделя 13): готово
- Вход и регистрация, те же проверки полей, что на сайте.
- Сессия сохраняется; access-токен обновляется сам через refresh-токен.
- Главная: итоги месяца (семья, мои расходы, лимиты, остаток), предупреждения о превышении, полосы лимитов по категориям, выбор месяца.
- Расходы: список своих расходов за месяц, итог, удаление свайпом с кнопкой «Отменить».
- Добавление расхода: категория, сумма, дата (не в будущем), заметка.
- Цвета и иконки категорий как на сайте, интерфейс на русском.

## Часть 2 (неделя 14): план
- Отчёт и сравнение с прошлым месяцем.
- Фильтры и поиск по расходам, изменение расхода.
- Профиль: имя, email, смена пароля.
- Достижения и оценка бюджета.
- Telegram, регулярные платежи, ИИ-помощник.
- Добавление члена семьи (админ приглашает участника): backend, сайт и приложение.

## Запуск
```bash
cd mobile
flutter pub get
flutter run                     # по умолчанию backend https://bis-kbtu.onrender.com
flutter run --dart-define=API_BASE=http://10.0.2.2:8000   # локальный backend из Android-эмулятора
flutter test                    # тесты: валидация, API-клиент, экран входа
```

## Структура
- `lib/api/` — модели и API-клиент (токены, повтор запроса после refresh, ошибки на русском)
- `lib/validation.dart` — те же правила, что `frontend/src/lib/validation.ts`
- `lib/screens/` — вход, регистрация, главная, расходы, новый расход
- `lib/widgets/` — выбор месяца, полоса лимита, общие элементы
